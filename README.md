# Uncanny Lab
## 프로젝트 개요
* 1대의 PC에서 두 플레이어가 협동하여 미로를 탈출하는 게임
  - 단절된 두 맵에 있는 플레이어는 각자 제한된 시야에서 미로를 통과해 탈출구를 찾아야 한다.
  - 각자의 맵에는 상대방이 미로를 통과하게 해주는 장치들이 있어 협동이 요구된다.
  - 미로를 통과하는 과정에서 암호 단서를 찾아, 탈출구에서 암호를 입력하면 클리어.
* 기술: Unity, C#
* 제작팀원: 4명 - 개발 1인(본인), 그래픽 2인, 음향선정 1인
* 제작 기간: 2주
